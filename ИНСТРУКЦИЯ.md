# Как запустить

Всё приложение уже написано. Сама программа (кнопки, тексты) — на английском,
как ты просила. Эта инструкция — на русском, только для тебя.

## Что уже готово
- `index.html` — редирект на вход
- `admin/login.html` — вход/регистрация
- `admin/clients.html` — список клиентов (кафе/бизнесов)
- `admin/client.html` — карточка клиента, оплата, список QR-групп
- `admin/group.html` — один QR-код: сам код, кнопки-ссылки, товары (фото+видео)
- `scan.html` — то, что видит покупатель после сканирования QR
- `api/` — два файла для Stripe (авто-оплата)
- `sql/schema.sql` — структура базы данных для Supabase

## Шаг 1 — Supabase (только база данных, без файлов)
1. Зайди в свой аккаунт Supabase → создай новый проект.
2. Слева → **SQL Editor** → New query → вставь содержимое файла `sql/schema.sql` → Run.
3. Слева → **Project Settings → API** → скопируй:
   - `Project URL`
   - `anon public` key
4. Открой файл `js/supabase-client.js` и вставь эти два значения вместо
   `YOUR_SUPABASE_PROJECT_URL` и `YOUR_SUPABASE_ANON_KEY`.

Фото и видео здесь больше не хранятся — они идут в Cloudflare R2 (шаг 3.5 ниже).
Supabase теперь отвечает только за базу данных и твой вход в кабинет.

## Шаг 2 — вход в свою же панель
Supabase Auth уже настроен. Просто открой `admin/login.html`, нажми
"Create an account", введи свой email и пароль — это будет твой единственный
логин в кабинет.

## Шаг 3 — Vercel (чтобы всё заработало по ссылке)
1. Загрузи всю эту папку в GitHub (или используй Vercel CLI / drag-and-drop
   в Vercel Dashboard).
2. В Vercel → New Project → выбери эту папку.
3. Deploy. Получишь ссылку вида `https://твоё-имя.vercel.app`.

## Шаг 3.5 — Cloudflare R2 (фото/видео), переменные окружения
Бакет `zmotion` уже создан, публичный доступ включён. Осталось указать
Vercel'у, как в него писать — но сами ключи идут только в настройки Vercel,
никогда не в файлы сайта:

1. В Vercel → Settings → Environment Variables добавь:
   - `R2_ACCOUNT_ID` = `847b5b3886edd1838e46614f46bfc708`
   - `R2_ACCESS_KEY_ID` = (тот, что показал Cloudflare при создании токена)
   - `R2_SECRET_ACCESS_KEY` = (тот же экран, Secret Access Key)
   - `R2_BUCKET_NAME` = `zmotion`
   - `R2_PUBLIC_URL` = `https://pub-2ae26cd4c09d45f986aaf4c82369945f.r2.dev`
2. Redeploy (Vercel → Deployments → на последнем деплое ⋯ → Redeploy), чтобы
   переменные подхватились.

**Важно:** тот Secret Access Key, что показал Cloudflare, больше нигде не
покажется. Если потеряешь — создаёшь новый токен точно так же и обновляешь
переменную в Vercel.

## Шаг 4 — Stripe (авто-оплата), можно позже
Раз аккаунт уже есть:
1. В Vercel → Settings → Environment Variables добавь:
   - `STRIPE_SECRET_KEY` — из Stripe: Developers → API keys → Secret key
   - `SUPABASE_URL` — тот же, что и раньше
   - `SUPABASE_SERVICE_ROLE_KEY` — Supabase: Project Settings → API →
     **service_role** key (не anon! этот держи в секрете)
   - `SITE_URL` — твоя ссылка на Vercel из шага 3
2. Deploy ещё раз, чтобы переменные подхватились.
3. (Позже, для авто-обновления статуса оплаты) Stripe Dashboard → Developers
   → Webhooks → Add endpoint → укажи `https://твоя-ссылка/api/stripe-webhook`,
   события: `checkout.session.completed`, `invoice.payment_failed`,
   `customer.subscription.deleted`. Скопируй "Signing secret" → добавь как
   `STRIPE_WEBHOOK_SECRET` в Vercel.

Без Stripe всё остальное (фото, видео, QR-коды, AR) работает полностью —
просто кнопка "Manage payment" не будет активна, пока не подключишь эти шаги.

## Как всё это работает вместе
1. Заходишь в `admin/clients.html` → добавляешь клиента (кафе).
2. Открываешь клиента → "Add QR group" (например "Меню").
3. Внутри группы → "Add item" → загружаешь фото блюда + видео.
   Браузер сам "обучает" фото для распознавания камерой (несколько секунд).
4. Скачиваешь QR-код этой группы → печатаешь.
5. Покупатель сканирует → камера открывается → наводит на фото → видео
   играет поверх → через 2-3 секунды можно убрать телефон, видео продолжает
   играть на весь экран.
6. Если в группе несколько товаров — сначала покажется список на выбор.

## Важный технический нюанс — распознавание нескольких товаров одним QR
Сейчас: если в QR-группе несколько товаров, покупатель сначала видит список
(картинки), выбирает нужное фото — и дальше камера ищет именно его. Это
надёжно работает уже сейчас.

Более "магический" вариант — когда камера сама распознаёт любое фото из
группы без выбора — технически возможен, но требует отдельного шага
дообучения (объединение всех фото в один файл распознавания). Это можно
добавить позже, когда проверим базовую версию на реальном телефоне.

## Если что-то не работает
Библиотека распознавания фото (MindAR) время от времени немного меняет свои
названия функций между версиями. Если при добавлении товара в `group.html`
вылезет ошибка на этапе "Preparing AR recognition" — напиши мне, пришлю
исправленный код под актуальную версию библиотеки.
